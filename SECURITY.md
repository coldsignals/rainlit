# Security

Found a way to get at someone's account, messages, files or calls, or anything else that
shouldn't be possible? Please email **rainlit.app@gmail.com** instead of opening a public
issue, so it can be fixed before it's out in the open. Say what you found and how to
reproduce it. You'll hear back.

If you run your own Rainlit, keep it updated (see [SELF-HOSTING.md](SELF-HOSTING.md),
step 10): fixes reach your server when you update it.
